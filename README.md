# Netflix Content Analysis: Excel Data Visualization Project

Data Visualization (Microsoft Excel) internship project at **Auspify Technologies**.
Cleaned a Netflix titles dataset and built pivot tables, charts and interactive dashboards in Microsoft Excel.

## Tools Used
Microsoft Excel (Pivot Tables, PivotCharts, Slicers, Formulas, Dashboard Design)

## Dataset
Netflix titles dataset (8,783 records after cleaning): 6,121 Movies and 2,662 TV Shows.

## Tasks Completed
| Task | Description |
|---|---|
| Task 1 | Data Cleaning & Chart Preparation |
| Task 2 | Netflix Content Distribution Dashboard |
| Task 4 | Netflix Release Trend Visualization |
| Task 6 | Executive Netflix Analytics Dashboard |

## Data Cleaning
- Checked duplicate records (none remained in the final dataset)
- Labelled missing Director and Country values as "Unknown" to retain records
- Converted date_added to a proper date format
- Created new fields: Year_Added, Rating_Group, Duration_Value, Duration_Unit, Primary_Genre, Release_Decade

## Key Findings
- Movies make up about 70% of the catalogue; TV Shows about 30%
- Content additions peaked in 2019 (2,012 titles)
- Release-year volume peaked in 2018 (1,143 titles)
- The 2010s hold 5,907 titles (67.3% of the catalogue)
- TV Shows grew from about 20% of releases in 2010 to 53% in 2021
- Dramas (1,597) and Comedies (1,207) are the top genres
- Adults is the largest rating group (4,003 titles), followed by Teens (2,645)
